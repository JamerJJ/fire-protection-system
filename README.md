# Fire Protection System

Backend project for managing fire protection inspection data across buildings, fire systems, components, inspections, and deficiencies.

## Tech Stack
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker

## Current Status
- PostgreSQL database running with Docker
- Core schema created
- FastAPI project structure set up

## Planned Features
- Buildings CRUD API
- Fire systems and components management
- Inspection and deficiency tracking
- Synthetic data generation
- Dashboard and ML-based risk insights
